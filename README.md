## Notes

```
jacks: neutrik from shared effects lib
capacitors: Capacitor_THT:C_Rect_L7.0mm_W2.5mm_P5.00mm
resistors (flush): Resistor_THT:R_Axial_DIN0207_L6.3mm_D2.5mm_P10.16mm_Horizontal
alpha 9mm pots: Potentiometer_THT:Potentiometer_Alpha_RD901F-40-00D_Single_Vertical

CASE:
outer dims: 120x65 mm
wall depth: 2 mm
usable inner space: 102x60 mm
screw area: 8.6x8.6 mm

center point: 160.02 x 101.6 mm

pots minimum 12mm from top
stomp switch ~34mm from bottom
```
